# Biblioteca Virtual - Proyecto Escolar

Este proyecto es el resultado de la evaluación en condición de libre para la materia Prácticas Profesionalizantes II.

## Descripción del Proyecto
Se trata de una aplicación web para la gestión de una Biblioteca Virtual. Las principales funcionalidades son:
- Catálogo de libros (CRUD).
- Control de stock de ejemplares.
- Registro y seguimiento de préstamos a usuarios.

## Estructura del Repositorio
- `PMI.md`: Plan de Gestión del Proyecto, conforme a los requisitos de la cátedra.
- `historias_de_usuario.md`: Documentación de las historias de usuario que guían el desarrollo.

## Cronograma de Seguimiento
El período de desarrollo es de 6 semanas, con encuentros de seguimiento los días Lunes a las 20:00 horas.
